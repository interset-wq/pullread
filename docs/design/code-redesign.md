# 代码查看页改版设计规范（2026-11 定稿）

来源：真机截图审计（hash_table.c · 253 行实测，含长按选中态）+ 三轮迭代设计板。
**设计基准：模仿 GitHub Mobile 的文件查看（blob）范式**（用户指定）。
定稿板：`docs/design/code-redesign/`——手机常态与选择态 `boards-gh.png`、
平板双栏与竖屏 `boards-tablet.png`；过程稿在 `temp/code-redesign/`，不入库。
本文是 Flutter 实现的依据；改版动这里时同步更新。

## 1. 要修的问题（真机审计）

1. 长行右缘被切无渐隐提示（底部滚动条首屏不感知）
2. 选中态绿底横条压在 meta bar 下，视觉打架
3. meta bar 复制 + 选中条复制两个复制入口重复
4. 头部三图标（大纲/搜索/换行）无标签但密度合理，保留

## 2. 定稿设计

### 2.1 手机（< 600dp）——GH Mobile 式结构

```
头部：返回 + 文件名（等宽字体）+ 大纲 + 搜索 + 换行(⇄)
面包屑行：ai / rag / basics / hash_table.c（仓库段松绿加粗，当前文件墨色等宽）
信息 chip 行：●C（语言圆点）· 253 行 · 8.2 KB + 右侧复制钮（唯一复制入口）
代码区（blob 式）：
  行号右对齐灰阶，等宽 13px、行高 2.0；语法配色对齐 GitHub Light
  长行横向滚动，右缘渐隐提示 + 底部滚动条
```

### 2.2 选择态（长按选行）

```
选中范围 = 整块高亮：连续浅绿底块（#E9F2ED）+ 左缘 3px 松绿指示条，行号列同块覆盖
底部浮出工具条（浅色白卡）：复制 / 分享 / 导出长图 / 取消
  白底 + 1px 描边 #E5E2D8 + 投影，图标深色，激活项松绿 tint
  ——浅色模式禁止黑色浮层（用户确认）
```

### 2.3 平板

- **横屏（≥ 1000dp）**：符号大纲**常驻侧栏**（约 280dp，浅底 #FBFAF6，
  当前符号松绿高亮 + 右缘指示条；T=类型 / F=函数前缀分级）+ 代码双栏；
  头部大纲钮消失（侧栏即大纲）。
- **竖屏（600–1000dp）**：同手机结构（chip 行 + blob + 大纲钮）。

## 3. 视觉 token（沿用 `docs/design/home-redesign.md`，新增/覆盖）

| Token | 值 |
|---|---|
| 代码底 | 纯白 `#FFFFFF`（区别于阅读页纸白） |
| 面包屑 | 12.5px；仓库段 `#1F6F54` 加粗，分隔 `/` `#C9C6BA`，文件名墨色等宽 |
| 信息 chip | 底 `#F1EFE7` 圆角 999，12px `#3A382F`；语言圆点 8px `#1F6F54` |

| 选中块 | 底 `#E9F2ED` + 左缘 3px `#1F6F54`；浅色工具条白卡描边 `#E5E2D8` |
| 符号侧栏 | 宽 280dp 底 `#FBFAF6`；当前项 `#E9F2ED` + 右缘 3px 松绿 |

## 4. 交互规则

1. 复制入口唯一：chip 行右侧复制钮；选中态的复制在工具条内（同一动作不同范围）。
2. 换行 ⇄ 保留：切换换行/横向滚动；横向滚动时右缘渐隐 + 滚动条。
3. 大纲：手机/竖屏为抽屉（同阅读页 TOC 规则）；平板横屏常驻侧栏；当前符号跟随滚动高亮。
4. 选择：长按行进入选择态，拖动扩展为行范围；工具条四个动作（复制/分享/导出长图/取消）。
5. 深色模式：代码底用 GH Dark 对应色阶；工具条深色卡（与浅色对偶）。

## 5. 实现落点（供开发侧）
