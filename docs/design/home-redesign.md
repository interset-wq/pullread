# 首页改版设计规范（2026-11 定稿）

来源：iOS 真机验收期间的首页 UI 审计 + 四轮迭代设计板（定稿板：
`docs/design/home-redesign/`——三方向对比 `boards.png`、切换式双态 `iter4.png`、
少内容态定稿 `iter9.png`；过程稿在工作区 `temp/home-redesign/`，不入库）。
本文是 Flutter 实现的依据；改版动这里时同步更新。

## 1. 要修的问题（来自真机审计）

1. 置顶图钉出现两次（大图钉 leading + 小图钉 action）
2. 仓库卡又高又空：信息挤左、右侧空洞，三个尾随按钮拥挤
3. 垃圾桶（破坏性操作）常驻每行
4. 四种卡片风格同屏（薄荷绿 / 横滑灰卡 / 描边 / 灰填充）
5. 继续阅读与最近阅读第一条重复；最近阅读文本全截断
6. 平板少内容时大片空白

## 2. 定稿结构

### 2.1 手机（宽度 < 600dp）

```
头部：logo + 搜索 + 收件箱(角标) + ⋮        ← 不变
继续阅读：细分隔线行（无卡片）               ← 安静上半
  圆形播放图标 | 小节头「继续阅读 · <repo> · 已读 n%」
  文件名（单行截断） + 3px 进度条
最近阅读：小节头 + 「全部 ›」右对齐
  ≤ 5 条细分隔线行：时钟图标 + 文件名 · repo，更多走「全部 ›」
切换器：segmented「仓库 · N | 本地文件夹 · M」 ← 互斥显示
  仓库 Tab：白卡列表（见 token），无本地元素；
    添加仓库走 + FAB，Tab 内不放添加入口
  本地 Tab：文件夹白卡（绿 tint 图标章）+ 虚线「添加本地文件夹」卡；
    FAB 在本地 Tab 隐藏（唯一添加入口是虚线卡）
FAB：+（品牌松绿 #1F6F54）
```

### 2.2 平板（宽度 ≥ 600dp）

- **竖屏**：内容居中限宽（约 600dp 内容带）；
  最近阅读/仓库内容用双列网格；单 repo 时仓库为全宽大卡。
- **横屏（≥ 1000dp）**：双栏——左栏（约 400dp）继续阅读 + 最近阅读（全局区），
  右栏 segmented 切换器 + 当前 Tab 内容（双列网格）+ `⋮`。
- **少内容态（关键）**：元素放大 + 信息增密，不缩角留白：
  - 继续阅读升级大 hero 卡（剩余约 n 分钟、上次读到 x 节、大进度条）
  - 最近阅读双列缩略卡（编号章 + 标题 + repo · 时间）
  - 单 repo 全宽大卡（同步状态点、文件数、最近读）
  - 横屏右栏追加「仓库内热门目录」双列（真实扫描数据）+ 轻引导空态卡

## 3. 视觉 token（全页只有一套）

| Token | 值 |
|---|---|
| 纸底 | `#FFFFFF`（纯白；2026-11 起统一，原 `#FBFAF6` 弃用） |
| 白卡底 | `#FFFFFF`，1px 描边 `#E5E2D8`，圆角 16 |
| 分隔线 | `#F2F0E8`（行）/ `#EFEDE5`（hero 下沿） |
| 主绿 | `#1F6F54`（FAB、进度条、monogram 章底、「全部 ›」） |
| 绿 tint | `#EDF5F0`（本地文件夹图标章、缩略章底） |
| 墨色标题 | `#26241E`；次级 `#3A382F`；元信息 `#A5A296`；节头 `#8A887E` |
| 置顶角标 | 标题旁 12px 单枚图钉（`#C99A2E`）；无大图钉 leading |
| 卡片内边距 | 16；卡间距 10；行内边距 11 |
| 收件箱角标 | `#E5443B` 白字圆角 9 |

monogram 章：repo 首字母，白字绿底 40×40（圆角 12）；大卡态 56×56。

## 4. 交互规则

1. **图钉只出现一次**：置顶状态 = 标题旁小角标；置顶/取消操作收进卡片 `⋮`
   （列表行右侧只留 `⋮` + 箭头或仅箭头；删除/置顶均进 `⋮` 菜单）。
2. **垃圾桶不常驻**：进 `⋮` 菜单，红色 destructive 项，点击需确认。
3. **仓库与本地互斥**：切换式，任何时刻只显示一类；Tab 各带计数。
4. **最近阅读 ≤ 5 条**，超出走「全部 ›」页；与继续阅读当前文件去重。
5. **添加入口各归其区**：仓库 → FAB（仅仓库 Tab）；本地 → 虚线卡（仅本地 Tab）。
6. 空状态：仓库 Tab 无仓库时用大空态卡（添加引导）；本地同理。
7. 深浅色模式：色值按主题映射（纸底/白卡/分隔线成对取暗色对应值）。

## 5. 实现落点

- `lib/src/ui/home_page.dart`：区块重排 + 切换器 + 平板布局（LayoutBuilder 三档：
  <600 / 600–1000 / ≥1000）
- `lib/src/ui/home_feed.dart`：卡片/行组件按本规范重写（token 常量收敛到这里）
- 删除/置顶操作移入 `⋮` 底部菜单；空态卡组件新增
- 「仓库内热门目录」：取自 note_index 的目录扫描计数（无数据时整块隐藏）
- 测试：`test/home_feed_test.dart` 按新结构更新（区块顺序、互斥、去重、截断）
