## 1. 要修的问题（真机审计）

1. 图标裸奔（无底色章），与目录树/收件箱等页的图标章语言不一致
2. 开关 on 态灰绿未对齐品牌松绿
3. 根页行距偏松，当前值列字号不统一
4. 平板横屏原设计为居中单列——用户指定改为 iPad 式双栏

## 2. 定稿设计

### 2.1 手机（< 600dp）

```
根页：
  头部：返回 + 「设置」大标题
  入口行：40px tint 图标章 + 标题/副题 + 右侧当前值（13px 灰，最长 110px）+ 箭头
  图标章配色：阅读/外观/存储 绿 tint；仓库 松橙；文件/关于 灰
  底部 slogan「PullRead · 克隆一次，常读常新」
子页（阅读与显示为代表）：
  头部右侧「恢复默认」松绿文字钮
  分组头（排版 / 阅读行为，12.5px 灰大写字距）
  滑杆行：章 + 标题/副题 + 右侧值（松绿 700）；滑轨 4px，已过段松绿，圆点松绿
  开关行：章 + 标题/副题 + 开关（on 态 #1F6F54，off 态 #D9D6CB）
```

### 2.2 平板

- **横屏（≥ 1000dp）——iPad 式双栏**（用户指定）：
  左类别栏 340dp（底 `#F4F2EB`），类别行 = 章 + 标题/副题；
  **当前类别松绿实底白字**（与阅读页 TOC 主钮同色系），其余浅底白字。
  右内容栏：类别标题 + 「恢复默认」+ 该类别全部设置项（同手机子页组件）。
  类别与内容联动，单列切换不再跳页。
- **竖屏（600–1000dp）**：同手机结构，居中限宽 640dp。

## 4. 交互规则

1. 横屏双栏：左侧点类别 → 右栏切换内容；选中态实底高亮；无返回跳页。
2. 滑杆拖动即时更新右侧数值；松手落库。
3. 「恢复默认」带二次确认（涉及多个值时）。
4. 根页箭头行手机/竖屏 = push 子页；横屏 = 不存在（根页即左栏）。
5. 深浅色：章底/开关 off 底/分组头/分隔线成对映射。

## 5. 实现落点（供开发侧）

- `lib/src/ui/settings/`：根页与子页行组件统一（图标章/值列/开关/滑杆）
- 平板：LayoutBuilder ≥1000dp 双栏（类别列表 + 内容 pane），选中态状态管理
- 测试：双栏联动、恢复默认、滑杆落库
