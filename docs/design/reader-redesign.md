# 阅读页改版设计规范（2026-11 定稿）

来源：真机截图审计（安卓 1280×2772 实测）+ 六轮迭代设计板（定稿板：
`docs/design/reader-redesign/`——手机菜单态与常态 `boards5.png`、平板双栏与竖屏
`boards6.png`；过程稿在工作区 `temp/reader-redesign/`，不入库）。
本文是 Flutter 实现的依据；改版动这里时同步更新。

## 1. 要修的问题（真机审计）

1. 表格横向溢出首屏无渐隐提示（有 ⇄ 换行开关但不知道可横滑）
2. 右侧三枚薄荷绿浮动钮叠正文，颜色与品牌松绿脱节
3. 「已回到上次位置」深色横幅盖正文中央
4. 上一章/下一章 pill 常驻与滚动条、浮动钮争抢底部
5. 标题瞬间截断
6. ⋮ 菜单 8 行纯文本堆叠，无分组无图标

## 2. 定稿设计

### 2.1 手机（< 600dp）

```
顶栏：返回 + 标题(单行截断) + 搜索 + 收藏星 + ⋮
阅读进度条：顶栏下 2.5px 细线，松绿，随阅读位置推进（保留现状，勿动）
正文：
  表格卡片化（描边 12 圆角），右上角 ⇄ 换行开关常驻，
  右缘渐隐提示可横滑（所有表格视为无限宽，默认横向滚动 + 底部滚动条）
右侧浮动钮（右下）：
  TOC 主钮：松绿 #1F6F54 圆角方块 48×48，常驻不隐藏
  上/下副钮：灰白小圆钮 36×36，位于主钮上方（跳上一处/下一处）
toast「已回到上次位置（约 n%）」：半透明胶囊，浮在 pill 上方，不遮正文
底部：上一章/下一章两枚白底 pill（单行截断，全名）
```

### 2.2 ⋮ 菜单重设计（保持真实 8 项，三组结构）

```
阅读          Raw 模式        [当前态值：关]
              字号            [标准]
书签          在此处加书签
              书签列表        [0]
导出与分享    复制全文        [MD / 纯文本]  ← 两项合并，右侧子值，点击出二级选择
              导出长图
              分享卡片
```
分组标题小字灰（`#A5A296`，11px 加宽字距），行高 40，图标 17px 灰。
**合并决策（已确认）**：复制全文 MD/纯文本合并为一项；「书签 (0)」改名「书签列表」。

### 2.3 平板

- **横屏（≥ 1000dp）**：**TOC 常驻侧栏**（约 260dp，当前节松绿高亮 + 右缘 3px
  指示条），阅读双栏；浮动 TOC 钮消失（侧栏即 TOC），上/下副钮保留在阅读栏内。
- **竖屏（600–1000dp）**：居中限宽阅读栏（约 560dp 内容带，行长可控）；
  TOC 仍为常驻浮动钮 + 上/下副钮（同手机）。底部上一章/下一章 pill 必须保留，
  避免少内容时空洞。

## 4. 交互规则

1. TOC 常驻：手机/平板竖屏浮动主钮不随滚动隐藏；平板横屏以侧栏形态常驻。
2. 上/下副钮：跳上一处/下一处标题；平板横屏放在阅读栏内。
3. toast：恢复位置提示半透明、不阻塞点击、3 秒自动淡出（B 方向已确认）。
4. 表格：⇄ 切换换行/横向滚动；横向滚动时右缘渐隐 + 底部滚动条。
5. ⋮ 菜单：分组结构见 2.2；Raw 模式/字号显示当前态值；点外部关闭。
6. 上一章/下一章：单行截断；滚动向下时收起、停止滚动后浮现（平板横屏常驻）。
7. 深浅色：色值成对映射（分隔线/卡底/菜单底）。
