# 多开阅读（Split Reader）

> v2 M3。实现见 `lib/src/ui/reader/split_reader_page.dart`。视觉基准仍以
> [`global-style.md`](global-style.md) 为准，不新增主题色。

## 入口

- 首页 AppBar「多开阅读」图标（`Icons.vertical_split_outlined`），所有窗口宽度
  都可用。
- 候选文档来自跨来源「最近阅读」；选择器为底部弹层，展示文件名与来源目录。
- 同一篇文档不能在左右栏重复打开。

## 布局

| 宽度 | 形态 |
| --- | --- |
| ≥900 dp | 左右两栏并排，中间 1dp 分隔线 |
| <900 dp | 单栏显示，底部 `SegmentedButton` 切换「左栏 / 右栏」 |

- 两栏各自持有独立 `Navigator` 与 `ReaderPane(embedded: true)`；切换栏或旋转
  不重建另一栏的阅读状态。
- 每栏顶部为紧凑栏：关闭、标题、书目录（书内）、查找、收藏、更多。
- 空栏显示图标、「左/右栏还没有文档」和「选择文档」按钮。
- 更多菜单在嵌入形态下用底部弹层承载 Raw、字号、书签、复制、编辑、导出。

## 交互

- 关闭某栏只清空该栏，不影响另一栏。
- 栏内上一篇/下一篇、编辑页仍在栏内导航栈中打开。
- 多开状态仅当前页面会话有效，不持久化。
