# iOS / iPadOS 真机验收清单

> 目标设备：iPad（第 5 代，iPadOS 16.x），可选 iPhone 对照。
> 构建来源：GitHub Actions → **iOS build** → Artifacts →
> `pullread-ios-unsigned`（`PullRead-unsigned.ipa`）。
> 该包**未签名**，CI 不保存任何签名证书；安装前必须用个人 Apple ID 或开发者
> 证书重签。iOS 15.0+，Bundle id `com.intersetwq.pullread`。

## 1. 安装与签名

1. 在 Actions 运行页下载 `pullread-ios-unsigned`，解压得到
   `PullRead-unsigned.ipa`。
2. 任选一种方式重签并安装：
   - **Sideloadly**（Windows/macOS）：连接 iPad，拖入 IPA，填 Apple ID；
   - **AltStore**：在 iPad 上通过 AltServer 安装；
   - **Xcode**：`flutter build ios --release` 后用 Xcode 选择真机运行。
3. 首次安装后到 **设置 → 通用 → VPN 与设备管理** 信任开发者证书。
4. iOS 16 需在 **设置 → 隐私与安全性 → 开发者模式** 打开开发者模式并重启。
5. 免费 Apple ID 签名 **7 天过期**；过期后应用无法启动，重新签一次即可，不需要
   重新克隆仓库（应用数据仍在）。

失败排查：

- `Unable to install ...`：先删除旧版本；签名证书或 Bundle id 冲突。
- 启动秒退：证书未信任 / 描述文件过期 / 开发者模式未开。
- 安装工具提示设备版本过低：确认 iPadOS ≥ 15。

## 4. iOS / iPad 特有项

### 4.1 本地文件夹（重点，预期可能与 Android 不同）

- [ ] 首页「打开本地文件夹」：iOS 文件选择器能选择目录或文件。
- [ ] 授权后能镜像并阅读 Markdown / 代码 / 图片。
- [ ] 编辑 Markdown → 保存：原文件夹内容同步更新。
- [ ] **杀掉应用再启动**：原文件夹授权是否仍然有效？若失效，记录现象。
- [ ] 写回失败是否进入「设置 → 存储与数据 → 未写回的修改」。

> iOS 的目录持久授权与 Android SAF 不同，`file_selector` 在 iOS 上可能只提供
> 临时访问。此项以实际行为为准，不要求一次通过，但必须记录。

### 4.2 手势与输入

- [ ] 音量键翻页（iPad 音量键）：翻页且不弹系统音量条；文首/文末行为正常。
- [ ] 代码页长按选区：高亮与手指对齐，滚动几十行不累积偏移，复制正常。
- [ ] 双指缩放图片 / 全屏图表不误触翻页。
- [ ] 外接键盘（如有）：方向键滚动、Esc 返回、复制粘贴正常。
- [ ] 鼠标/触控板（如有）：点击、滚动、返回手势正常。

### 4.3 系统行为

- [ ] 分享到文件 / 微信 / 邮件等目标正常。
- [ ] 后台切回前台不丢阅读位置。

崩溃或白屏时优先提供：

1. Xcode 设备日志（`.ips` / `.crash`）；
2. 复现步骤与是否必现；
3. 当时是否处于分屏、深色模式、最大字号。

## 7. 已知限制

- 未签名 IPA 不能直接安装，也不能上 TestFlight；每次签名 7 天有效。
- iOS 上没有 Android 的 5 套桌面图标切换。
- 本地文件夹持久授权可能受限，见 4.1。
- 版本号在 iOS 上会把预发布后缀转成数字（例如 `1.12.0-rc5+25` 显示为
  `1.12.05+25`），这是 iOS 版本号格式限制，不是构建错误。
